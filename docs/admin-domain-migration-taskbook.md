# 管理后台独立域名迁移任务书

## 目标

将管理后台从主站 `/admin/` 迁移到 `https://admin.freedompost.thinderbox.uk`，并在 Cloudflare Access + MFA 后面保护；应用层继续执行管理员会话认证。先部署到开发测试服务器 bingo，完成验收后再发布生产。

## 六个员工任务与执行提示词

1. **安全架构师**：审查认证、授权、Cookie、CSRF、CORS、WAF 和日志；输出 High/Critical 风险清单及修复建议。不得以隐藏路径替代认证。
2. **前端工程师**：将管理 SPA 的 Vite base、资源路径、路由刷新和 API 调用适配独立域名根路径；补充登录、登出、刷新、错误状态测试。
3. **后端工程师**：核对 `/api/admin/*` 的服务端授权、会话失效、限流和错误响应；增加必要的 Origin/CSRF 防护，保持 API 契约兼容。
4. **网关/部署工程师**：配置 Caddy、Docker 和环境变量，使管理域名只提供管理 SPA 与管理 API；主站旧 `/admin/` 返回 404；验证配置、健康检查和回滚。
5. **测试工程师**：建立测试矩阵，执行单元、集成、构建、浏览器 Smoke、未登录/越权/CSRF/限流和回归测试；不得弱化断言或跳过失败。
6. **运维/发布负责人**：记录当前版本，先发布 bingo 测试环境；收集日志、指标和验收证据；测试通过并获发布门禁后再发布生产，保留一键回滚点。

## 发布门禁

- 无未解决 Critical/High 问题；
- 目标测试、构建、lint、类型检查通过；
- bingo 上管理域名、主站旧路径、登录和关键 CRUD Smoke 通过；
- Cloudflare Access 保护策略和 MFA 已验证；
- 生产部署前记录提交哈希、备份/回滚版本和健康检查结果。

## 回滚

保留当前生产镜像/提交和 Caddy 配置；验证失败时停止扩散，恢复上一版本并重新执行健康检查与 Smoke Test。
