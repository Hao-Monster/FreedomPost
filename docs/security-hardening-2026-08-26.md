# Go 后端安全加固设计（2026-08-26）

## 1. 目标与完成条件

本次修复覆盖已通过本地动态攻击演练确认的 Go 后端漏洞。完成条件：

- 未授权请求无法获得付费文章正文、Markdown、搜索文本、自动摘要或附件信息。
- 付费文章评论读取、评论创建和附件上传必须通过读者购买权限校验。
- 文件名、响应 MIME 和下载策略完全由服务端检测结果决定，上传内容不能作为同源 HTML、JavaScript 或 SVG 执行。
- 推广订单价格和佣金只能由数据库中当前商品及推广加价规则在同一事务内计算。
- 推广账号停用或密码重置后，已有会话在下一次请求时立即失效。
- 内部管理请求签名绑定时间戳、一次性 nonce、方法、路径、管理员身份和请求体；重放请求被拒绝。
- Go 单元/集成测试、前端检查、依赖漏洞扫描和密钥扫描通过，且不存在已知 Critical/High。

## 2. 信任边界与关键不变量

### 2.1 付费内容

- `/api/reader/posts/:slug` 是付费正文的唯一公开授权出口。
- `/api/posts/:slug` 对 `paid` 文章仅返回元数据，正文相关字段和自动摘要为空。
- `/api/posts` 的付费文章摘要为空；搜索索引继续只包含 `public` 文章。
- paid-access 在未购买时同时清空 `contentHtml`、`excerpt` 和附件数量。

### 2.2 评论与附件

- 公开文章允许匿名评论；私密文章返回 404；付费文章要求有效读者会话和购买权限。
- 评论请求只信任附件 `id + claimToken`，名称、URL、MIME、大小、存储键和哈希均从数据库读取。
- 上传返回的 claim token 只保存哈希；附件只能被认领一次，并在创建评论的事务内锁定和绑定。
- 允许内联的类型仅为无脚本能力的位图、音频和视频；文本、PDF、压缩包和二进制强制下载；SVG 禁止上传。
- 匿名评论附件最大 25 MiB、每条评论最多 5 个附件；管理员仍受全局配置限制。

### 2.3 推广订单与会话

- 公开下单接口只接受既有契约 `productSlug + recommenderWechatId`；客户端价格、佣金、`markupPercent`、推广员 ID 和商品 ID 均不接受。
- 服务端按微信号解析 active 推广账号，并在一个数据库事务中读取 published/有库存商品及当前加价规则，订单只持久化服务端计算的价格、基础佣金和加价佣金。
- 加价范围固定为 0–1000%，数据库约束是最终防线。
- 批量商品加价单次最多 100 个 UUID；无效、重复或不存在的商品在事务提交前拒绝。
- 推广会话保存 `credentialVersion`；每次鉴权检查账号为 active 且版本一致。停用和密码重置都会递增版本。

### 2.4 内部服务认证

规范化签名串：

```text
timestamp\nnonce\nMETHOD\npath\nactor\nsha256(body)
```

- nonce 使用密码学安全随机数，服务端通过 Redis 原子计数保存 10 分钟；相同 nonce 第二次使用即拒绝。
- 内部管理接口额外要求非空 actor，且 actor 位于签名串内；读者权限检查允许空 actor。
- Redis 故障时沿用严格的进程内回退；错误不会导致放行重放请求。
- 所有非 2xx paid-access 响应在主 API 中作为错误处理，禁止把 404 页面包装成 200。

## 3. API 与数据兼容性

- 管理商品输入恢复 camelCase JSON 标签，同时兼容历史 `imageUrl`，规范字段为 `coverUrl`。
- 评论、附件、商品和工具的写接口同时返回现有嵌套对象与前端使用的顶层对象字段，避免 Go 切流造成契约回归。
- 新迁移为推广账号增加凭据版本，为附件增加认领令牌哈希，为推广订单增加佣金拆分和备注字段；迁移仅新增字段和约束，可先部署数据库再部署应用。
- 部署后旧推广会话因缺少凭据版本自动失效，需要重新登录。这是有意的安全行为。

## 4. 性能与健壮性

- 付费评论鉴权仅在 `paid` 分支调用内部服务；公开文章不增加跨服务请求。
- 浏览量、评论和付费文章在数据库/跨服务鉴权前执行按 IP 的粗粒度限流，避免伪造 cookie 放大内部请求。
- 推广订单将原先分散的商品/加价读取合并为一个事务，避免价格竞态和重复查询。
- 同一推广员/访客的点击唯一性通过事务级 advisory lock 串行判定，并发请求只产生一个 unique 记录。
- 匿名上传在进入 `io.ReadAll` 前限制为 25 MiB，并让 multipart 将较大内容落盘，限制并发内存风险。
- 内部重放缓存键只保存 nonce 哈希并自动过期，不保存请求体或凭据。
- 就绪探针只返回稳定状态，不向公网返回 PostgreSQL/Redis 原始错误；详细错误仅进入服务日志。

## 5. 测试矩阵

| 风险/验收标准 | 层级 | 核心场景 | 预期 |
|---|---|---|---|
| 付费内容泄露 | 单元 + 集成 | 主 API、paid-access 未登录、已购买 | 未登录无正文/摘要；已购买有正文 |
| 付费评论越权 | 集成 | 未登录读取/创建/上传，已购买访问 | 未登录拒绝，已购买成功 |
| 同源活动上传 | 单元 + 集成 | HTML/JS/SVG、伪造扩展名、合法图片 | 活动类型拒绝或 `.txt` 下载；图片正常 |
| 附件元数据伪造 | 数据库集成 | 错误 token、重复认领、伪造 URL | 事务拒绝且不创建评论 |
| 订单金额篡改 | 数据库集成 | 注入客户端价格/加价、无效推荐人、下架/售罄商品 | 拒绝非契约字段，只使用事务内持久化规则 |
| 会话撤销 | 集成 | 停用、改密后的旧 cookie | 下一请求 401，新登录按状态处理 |
| HMAC 重放/身份篡改 | 单元 | 相同 nonce 重放、修改 actor/body/path | 第二次或篡改请求 401 |
| paid-access 契约 | 单元 | 四个内部路径、404/400/500 | 路径正确，所有非 2xx 返回错误 |
| 滥用统计 | 集成 | 伪造 visitor/date、重复 IP | 服务端日期/访客键生效，重复不计数 |
| 依赖与密钥 | 静态 | govulncheck、npm audit、gitleaks | 无可达漏洞，无未豁免秘密 |

## 6. 发布与回滚

1. 本地执行迁移、Go/Node 测试、race（可用环境）、构建、安全扫描和攻击回归。
2. 创建单一安全修复提交并推送 `main`；现有 `Deploy` workflow 会部署生产。
3. 部署后验证健康检查、公开/付费文章、评论授权、推广登录与订单、管理端内部服务。
4. 应用回滚可恢复上一提交；新增数据库字段保持兼容，不在回滚时删除。旧会话失效不可逆，但不影响业务数据。
